# Taylor Engineering logo pack for the in-house app (exported 2026-09-13)

Brand colours: navy #0f1f38, navy-dark #0a1628, gold #f0a500 (accents on dark only),
gold-ink #906300 (gold text on light), white #ffffff.

Rule: the "T" inside the mark is NEGATIVE SPACE. It is transparent in every file here.
Never fill it white. The original artwork had it painted white; that was rejected.

| File | Use |
|---|---|
| lockup-white-transparent.png (2842x659) | White type, transparent. On navy / dark / photo backgrounds. |
| lockup-dark-transparent.png (2842x659) | Dark type, transparent. On white and light backgrounds. |
| lockup-dark-on-white.jpg (2842x659) | Flattened on white. Documents, PDF report headers, email signatures. |
| mark-transparent.png (800x800) | The mark alone, transparent. Source for icons and small placements. |
| app-icon-1024-navy.png | App icon master, mark on navy. Generate every platform size from this. |
| app-icon-1024-white.png | App icon master, mark on white (light-theme stores / splash). |
| app-icon-1024-transparent.png | Mark centred in a 1024 square, transparent. |
| app-icon-1024-navy-maskable.png | Android adaptive / maskable icon: mark at 60% so circular masks don't clip it. |

Sizing guidance: lockups are 4.3:1. At 40px tall the lockup is ~172px wide; at 72px tall ~310px.
Minimum legible height for the lockup is about 28px; below that use the mark alone.
